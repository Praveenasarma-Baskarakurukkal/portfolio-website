## Tech Stack

- Next.js 16 (Turbopack) + TypeScript
- Tailwind CSS + Framer Motion
- Lucide React Icons

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
